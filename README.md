# ✨ Features

* 🛒 Display all products from API
* 🔍 View **detailed product information**
* 🔗 Dynamic routing using **React Router**
* ⚡ Centralized state management with **Redux**
* 📦 Clean and reusable component structure
* 🚀 Fast and responsive UI
